# 泰坦尼克号乘客幸存率数据分析报告

## 📊 项目简介
本项目基于泰坦尼克号乘客数据集，通过Python进行数据清洗与可视化分析，探究舱位、性别、年龄等因素对乘客幸存率的影响，验证“妇女儿童优先”和“舱位等级差异”的历史事实。

---

## 🔍 数据概览
数据集包含891名乘客的信息，核心字段包括：
- `Survived`：是否幸存（1=幸存，0=遇难）
- `Pclass`：舱位等级（1=头等舱，2=二等舱，3=三等舱）
- `Sex`：乘客性别
- `Age`：乘客年龄
- 其他字段：同行亲属数、票价、登船港口等

---

## 📈 分析结果与可视化

### 1. 舱位等级与幸存率
![舱位与幸存率](images/pclass_survived.png)

**结论：**
- 舱位等级与幸存率高度正相关：头等舱乘客幸存率超过60%，三等舱乘客幸存率不足30%。
- 这与历史事实一致，救生艇优先安排给头等舱乘客，舱位等级直接决定了获救机会。

---

### 2. 性别与幸存率
![性别与幸存率](images/sex_survived.png)

**结论：**
- 女性乘客的生存率远高于男性，超过70%的女性乘客获救，而男性生存率不足20%。
- 完全符合“妇女优先”的救援原则，女性乘客被优先安排登上救生艇。

---

### 3. 年龄与幸存率
![年龄与幸存率](images/age_survived.png)

**结论：**
- 儿童（0-12岁）的获救比例明显高于其他年龄段，符合“儿童优先”的救援原则。
- 18-60岁的成年男性遇难人数最多，是幸存率最低的群体。

---

### 4. 年龄段分组与幸存率
![年龄段与幸存率](images/agegroup_survived.png)

**结论：**
- 儿童组的幸存率超过60%，是所有年龄段中最高的。
- 老年组和成年男性组的幸存率最低，不足25%。

---

## ✅ 最终结论
1.  **舱位等级**是影响幸存率的核心因素，头等舱乘客的获救概率是三等舱的2倍以上。
2.  **性别**是幸存率的决定性因素，女性乘客的获救概率是男性的3倍以上。
3.  **年龄**与幸存率密切相关，儿童乘客的获救概率远高于成年和老年乘客。
4.  历史上的救援原则（妇女儿童优先）和舱位等级差异，直接体现在了幸存率数据中。
